## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 维护者 push/dispatch → Actions runner | 触发面只有本人 push 与 typed-boolean dispatch；runner 为 GitHub 托管临时环境 |
| Actions runner → GitHub Pages | OIDC 短时令牌（id-token: write）发布工件，无长期 secret |
| 构建产物 → 公网访客 | 断言把门在产物发布之前（upload 前的 smoke 步骤） |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-03 | Elevation/Info Disclosure | GITHUB_TOKEN 越权或外泄 | high | mitigate | 显式最小 permissions 块（contents: read / pages: write / id-token: write）；OIDC 短时令牌替代 PAT；仓库零 secrets 存量 |
| T-02-04 | Tampering | 未授权/误触发部署 | high | mitigate | D-16 双闸：deploy job if 条件同时要求 vars.DEPLOY_ENABLED 或显式 dispatch 输入；删除仓库变量即全局停部署（kill-switch） |
